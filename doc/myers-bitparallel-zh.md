# Myers 位并行编辑距离算法（fuzzy 搜索优化备选）

> 状态：原理记录 + 本项目适配分析，对应 TASK.md P2.3。
> 参考：G. Myers, *A fast bit-vector algorithm for approximate string
> matching based on dynamic programming*, JACM 1999；H. Hyyrö 的简化推导
> （本文公式采用 Hyyrö 版）。

## 1. 经典 DP 为什么慢

Levenshtein 标准解法填 (m+1)×(n+1) 的 DP 表（m=模式串长，n=文本串长）：

```
D[i][j] = min( D[i-1][j] + 1,                 // 删除
               D[i][j-1] + 1,                 // 插入
               D[i-1][j-1] + (a[i]≠b[j]) )    // 替换/匹配
```

O(n·m) 个单元格，每格 2~3 次比较取 min、带分支、读写内存中的 DP 行。
fuzzy 搜索场景下这个成本还要乘以词典词数（`search_fuzzy` 对每个
词典词 × 每个查询词各跑一遍）。

## 2. 两个关键观察

**观察 1（差值有界）**：DP 表相邻单元格之差恒 ∈ {−1, 0, +1}。
竖直方向 `D[i][j] − D[i-1][j]`、水平方向同理——一步编辑最多改变 1，
这是编辑距离的内在性质。

**观察 2（值不重要，差值才重要）**：差值只有三种取值，无需存单元格的
值，对每列只存两个**位向量**：

- `VP`（vertical positive）：bit i = 1 ⟺ 该列第 i 行相对上一行 **+1**
- `VN`（vertical negative）：bit i = 1 ⟺ **−1**
- 两者皆 0 ⟺ 差值为 0

一列 m 个单元格的全部信息压进 ⌈m/64⌉ 个机器字。分词产物的词长
几乎恒 ≤64 字节 → **整列就是一个 uint64**。

## 3. 核心：用 ALU 进位链替代 min 传播链

仅压缩存储不够——DP 一列内部有顺序依赖：一个匹配引起的低值会沿列
向下**连锁传播**（min 链），看似必须逐行计算。

Myers 的关键发现：该连锁传播与**二进制加法的进位传播同构**。一次
64 位加法，硬件在一个周期内把进位从 bit 0 波及到 bit 63——这正是
min 链要做的事。算法的核心一行：

```c
Xh = (((Eq & VP) + VP) ^ VP) | Eq;
```

`Eq & VP` 标出「此处字符匹配且上方差值 +1」的位置，`+ VP` 让进位沿
连续的 VP=1 区段链式传播——原本 m 步的逐行更新被 ALU 进位电路一条
指令完成。

## 4. 完整列转移（Hyyrö 版，处理文本第 j 个字符 c）

```c
Eq = Peq[c];                  // 预计算：模式串中字符 c 出现位置的掩码
Xv = Eq | VN;
Xh = (((Eq & VP) + VP) ^ VP) | Eq;
Ph = VN | ~(Xh | VP);         // 水平 +1
Mh = VP & Xh;                 // 水平 −1
if (Ph & kLastBit) ++score;   // 只追踪最后一行 = pattern 全长 vs 文本前缀的距离
if (Mh & kLastBit) --score;
Ph = (Ph << 1) | 1;
Mh <<= 1;
VP = Mh | ~(Xv | Ph);
VN = Ph & Xv;
```

初始：`VP = ~0`，`VN = 0`，`score = m`。`Peq` 每个模式串建一次
（字节字母表 = 256 个 uint64），摊销于整个词典扫描。
整列转移 ≈ **15 条寄存器位运算，零分支，零内存表访问**。

## 5. 加速来源（为什么不止 64÷15）

| 因素 | 经典 DP | Myers |
|---|---|---|
| 每列工作量 | m 格 ×（比较+min+分支） | ~15 条位运算（m≤64 时与 m 无关） |
| 分支 | 每格 2-3 个，预测易失败 | 0（score 两判可写成无分支） |
| 内存 | 读写 DP 行（cache 流量） | 全寄存器 |
| 指令级并行 | min 链串行 | 位运算依赖链短，超标量多发 |

理论密度收益 64 格/字 ÷ 15 指令 ≈ 4x，叠加去分支、去内存、ILP，
短模式串实测通常 **10~30x**。

## 6. 本项目适配要点（inverted.cpp `search_fuzzy`）

1. **单字版本即可**：查询词为分词产物，长度恒 ≤64 字节，无需多字块扩展。
2. **m 取查询词、n 取词典词**：`Peq` 按查询词预建，整个 shard 扫描复用。
3. **k-bounded 提前终止**：只需回答「距离 ≤ k？」（k=1/2）。score 超过
   `k + 剩余列数`（剩余列即使全 −1 也减不回来）即可放弃该词典词。
4. **既有剪枝保留**：S10.3 的字节长度差剪枝与本算法正交，继续生效。
5. **对照方案**：k≤2 时 Ukkonen 带状 DP（O(k·n) 标量）复杂度同样好，
   但 Myers 常数更小、核心 ~20 行、天然无分支，对「短词 × 海量词典词」
   形态更优。
6. **第二阶段（可选）**：位并行落地后若仍需压，可用 AVX2 把 4~8 个
   词典词的 VP/VN 打包进向量寄存器批量处理——优先级远低于本体。
